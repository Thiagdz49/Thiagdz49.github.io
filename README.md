# 🌐 Portfólio

Site pessoal desenvolvido com **HTML, CSS e JavaScript puro**, reunindo meus projetos, um pouco sobre mim e formas de contato.

🔗 **Acesse online:** [thiagdz49.github.io](https://thiagdz49.github.io/)

## 📋 Sobre

Este é o meu site de portfólio, criado para apresentar os projetos em que venho trabalhando, um resumo sobre minha trajetória e formação, além de canais de contato para quem quiser falar comigo.

## 🛠️ Tecnologias

- **HTML5**
- **CSS3**
- **JavaScript**

## 📂 Seções do site

- **Início** — apresentação geral
- **Sobre mim** — um pouco da minha trajetória e formação
- **Projetos** — trabalhos e projetos desenvolvidos
- **Contato** — formas de entrar em contato comigo

## 🚀 Como rodar localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/thiagdz49/thiagdz49.github.io.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd thiagdz49.github.io
   ```
3. Abra o arquivo `index.html` diretamente no navegador, ou use uma extensão como o **Live Server** (VS Code) para melhor experiência.

O site está publicado via **GitHub Pages**, direto a partir deste repositório.
